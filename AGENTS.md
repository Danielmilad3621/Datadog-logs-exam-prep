# Log Lab project rules
- This project is independently hosted on Vercel with a user-owned Supabase backend.
- Keep question data server-only and protect private study/progress endpoints.
- Preserve answer counting, mistakes tracking, and explicit sync conflict resolution.
- Keep secrets out of source control and browser bundles.
- Database changes belong in reviewed, versioned SQL migrations.
- Run unit tests, TypeScript checking, and production build before deploying.
